# Explicitly archived research evidence

Unlike transient, Git-ignored `results/` files, the `evidence/` folder
contains **deliberately committed original experimental artifacts**.
These are not synthetic/hypothetical result tables; they were generated
by an actual recorded execution and independently audited.

## Evaluation dated 2026-11-01

`evidence/evaluation_2026-11-01/` holds:

- `model1_runs.csv`, `model2_runs.csv`: all 300 method/seed/start records,
  including failures and final loss/curvature diagnostics.
- `model1_timings.csv`, `model2_timings.csv`: all 1,500 raw optimizer-only
  timing repetitions.
- `model1_summary.json`, `model2_summary.json`: per-dataset paired
  descriptive statistics, bootstrap intervals, dataset hashes, source code
  and package versions.

The accompanying reproducibility manifest is
`config/evaluation_provenance.json`. Compare its SHA-256 values with these
files if any result appears inconsistent. The explanations, caveats,
and academic interpretation are in `docs/FINAL_EVALUATION_RESULTS.md`.

**Do not overwrite this original archive** with a later run. Local
replications generated by `python -m scripts.run_comparison --execute`
belong in a new dated archive with separate source/config hashes.
